VERD-A Packs

Una alternativa sostenible para nuestro planeta 🌱

¿Qué es VERD-A Packs?

VERD-A Packs es una propuesta de bolsa sostenible diseñada para promover el cuidado del medio ambiente y reducir el uso de materiales contaminantes.

Beneficios

♻️ Reutilizable

Puede utilizarse múltiples veces.

🌱 Ecológica

Contribuye a reducir el impacto ambiental.

💪 Resistente

Diseñada para transportar productos de manera segura.

Nuestro proyecto

Este proyecto busca generar conciencia sobre el uso responsable de bolsas y fomentar alternativas sostenibles.
